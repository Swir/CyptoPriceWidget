## 🇬🇧 English

Crypto Price Widget is a compact PyQt desktop application for keeping selected cryptocurrency prices visible without opening a browser. It retrieves market data from the CoinGecko API and displays price and 24-hour change information in a dark, lightweight interface.

### ✨ Features
- live cryptocurrency prices in USD
- 24-hour percentage change
- green/red visual change indicator
- searchable cryptocurrency list
- pinned-token configuration stored in JSON
- automatic background refresh
- multiple historical application versions included in the repository

### 🚀 Run

```bash
git clone https://github.com/Swir/CyptoPriceWidget.git
cd CyptoPriceWidget
pip install PyQt5 requests
python v5.py
```

## 🇵🇱 Polski

Crypto Price Widget to niewielka aplikacja PyQt pozwalająca śledzić ceny wybranych kryptowalut bez ciągłego otwierania przeglądarki. Dane pobierane są z API CoinGecko, a program prezentuje aktualną cenę oraz zmianę z ostatnich 24 godzin.

### ✨ Funkcje
- aktualne ceny kryptowalut w USD
- procentowa zmiana 24h
- zielone/czerwone oznaczenie kierunku ceny
- wyszukiwarka kryptowalut
- przypięte tokeny zapisywane w JSON
- automatyczne odświeżanie w tle
- kilka wersji rozwojowych programu w repozytorium

### 🚀 Uruchomienie

```bash
pip install PyQt5 requests
python v5.py
```
